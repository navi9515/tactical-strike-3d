# 🔫 Tactical Strike 3D

Tactical Strike 3D is a realistic, action-packed 3D browser-based real-time multiplayer First-Person Shooter (FPS) game built with Node.js, Socket.io, and Three.js.

## ✨ Features
- 🎮 **Real-time 3D Multiplayer**: Fast, low-latency Socket.io synchronization for live online player combat.
- 🏗️ **Tactical Compound Map**: 3D arena featuring warehouses, shipping containers, concrete barricades, and elevated sniper towers.
- 🔫 **4 Weapons Loadout**: M4A1 Assault Rifle, AWM Sniper (with 4x Scope zoom), M4 Shotgun, and Tactical Pistol.
- 🔊 **Procedural Audio**: Web Audio API audio synthesis for realistic gunshots, reload sounds, footsteps, hitmarkers, and headshots.
- 📊 **Dynamic HUD**: Health/Armor meters, Kill Feed, Directional Damage flash, Radar Mini-map, and TAB Scoreboard.

## 🚀 Tech Stack
- **Frontend**: HTML5, CSS3, Three.js, Web Audio API
- **Backend**: Node.js, Express, Socket.io
